WINDOWS 설치 도우미

학생 활동 기록

학교 전용 Google Apps Script 웹앱을 순서대로 설치합니다.

시작하기 전에 관리자로 사용할 Google 계정으로 브라우저에 로그인하세요. 기존 학교 설치를 업데이트하는 기능은 아직 지원하지 않습니다.
  1. 1

    Apps Script API 켜기

    Google 설정 페이지에서 Apps Script API를 켠 뒤 이 창으로 돌아오세요.

    사용자 확인
  2. 2

    Google 로그인 승인

    기본 브라우저에서 프로젝트 설치 권한을 승인합니다. 인증 정보는 이 Windows 사용자 폴더에만 저장됩니다.

    대기
  3. 3

    프로젝트 생성 및 코드 업로드

    학교 전용 프로젝트를 만들고 설치 파일 12개만 업로드합니다. 중간에 실패하면 같은 프로젝트에서 이어집니다.

    대기
  4. 4

    최초 관리자 등록

    편집기에서 registerInitialSchoolAdministrator를 선택해 실행하고 Drive·Sheets·메일 권한을 승인하세요.

    대기
  5. 5

    웹앱 배포

    교사에게 전달할 학교 전용 웹앱 주소를 만듭니다.

    대기
설치 완료

웹앱에서 학교 설정을 마무리하세요.

학교명·학교급을 입력하고 중앙 자료를 새로 만들거나 기존 자료를 연결합니다.

교사 배포 전 Google Workspace 도메인 제한 또는 ALLOWED_TEACHER_EMAILS 설정을 확인하세요.

설치를 시작할 준비가 되었습니다.
